# Week 3 – JavaScript Interactive Webpage

## Project Overview

This project was completed as part of my Week 3 task during the YuvaIntern Frontend Web Development Internship.

The objective of the task was to add interactive features to a static webpage using plain JavaScript. The webpage was developed using HTML5 and CSS3, and JavaScript was integrated to provide dynamic behavior and improve the user experience.

## Objectives

* Add JavaScript functionality to a static webpage.
* Practice DOM manipulation.
* Implement event handling.
* Add interactive buttons.
* Create a responsive mobile navigation menu.
* Implement basic form validation.
* Dynamically update webpage content.
* Integrate HTML, CSS, and JavaScript smoothly.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Event Listeners
* Visual Studio Code
* Google Chrome

## JavaScript Features

### 1. Mobile Navigation

A JavaScript click event is used to open and close the navigation menu on smaller screens.

### 2. Dynamic Message

The "Click Me" button dynamically changes the message displayed on the webpage.

### 3. Form Validation

The contact form checks whether the name, email, and message fields have been entered correctly before displaying a success message.

## Testing

The webpage was tested using Google Chrome.

The JavaScript functionality was tested by:

* Opening and closing the mobile navigation.
* Clicking the interactive button.
* Submitting the form with empty fields.
* Entering an invalid email.
* Submitting the form with valid information.

## Challenges

One of the main challenges was connecting JavaScript with the correct HTML elements.

Another challenge was making sure that form validation worked correctly without refreshing the webpage.

These issues were solved using DOM selection, event listeners, conditional statements, and `event.preventDefault()`.

## Learning Outcome

This task helped me understand how JavaScript can be used to make a static webpage interactive.

I gained practical experience with DOM manipulation, event handling, form validation, class manipulation, and dynamic content updates.
